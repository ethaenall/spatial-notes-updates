# Spatial Notes updates

Downloadable app update artifacts. Application source is maintained separately in a private repository.

**99.0.3 is an isolated updater QA prerelease, not a customer release.** It uses a separate application identity and QA signing key. Analytics and connected services are disabled. It is not notarized or approved for general installation.

The production update feed has not been switched to this repository. Existing Spatial Notes 0.1.0 installations require a manual first update to an updater-enabled customer release.
